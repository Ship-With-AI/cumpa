<interfaces>
Extend the existing strict `ReviewDraftV1` comparison member with an optional immutable range provenance object containing requested labels, full pinned base/head OIDs, exact ordered pathspecs, and the 64-character lowercase range review key. A range draft must contain the complete matching object; an interactive draft must retain the existing comparison shape and pair-only path.

`draftPaths` selects `range.reviewKey` only from server-held range comparison data. It retains `comparisonKey(baseOid, headOid)` for interactive comparisons. The browser never supplies either key or a filesystem path.

The production ownership path is `createSessionApp -> createAppDraftStore -> createDraftStore`. `createAppDraftStore()` must pass the complete frozen `comparison.range` object into its `DraftComparison` only when `comparison.range` exists; its interactive branch must construct the exact existing pair-only object with no `range` member. The direct `createCapabilityRegistry()` fallback follows the same conditional shape, but `tests/api/draft.test.ts` must exercise the production `createSessionApp()` path without injecting a draft store.
</interfaces>
