<interfaces>
The schema-version policy resolved in `12-RESEARCH.md` is mandatory:
- Existing interactive exports remain strict `ReviewExportV1` documents with exact current canonical bytes and Markdown.
- Range exports are strict `ReviewExportV2` documents containing requested base/head labels, pinned full base/head OIDs, exact ordered pathspecs, and the 64-character lowercase range review key.
- Parsing and rendering use a strict discriminated union. Range provenance is never emitted under schema version 1, and existing interactive exports are never silently upgraded.

Interactive export directories retain the server-derived `<baseOid>..<headOid>` name. Range directories use only the server-derived 64-hex review key. Both names are validated before joining to `.cumpa/exports`; request bodies never provide a publication name or path.
</interfaces>
