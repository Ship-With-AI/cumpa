| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-14 | Tampering | conflict UI | mitigate | Separate canonical/buffer state; accepted or explicit reload are the only canonical replacements; no force/merge/retry. |

| T-03-16 | Information Disclosure | Markdown links/errors | mitigate | Raw HTML/plugins off, dangerous schemes inert, safe attributes, no absolute path/raw JSON/stack trace. |
