<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Repository draft bytes → parser/schema | Repository-local JSON is untrusted and may be malformed, invalid, or newer. |
| Browser recovery intent → filesystem | Browser may confirm recovery but cannot choose paths or bytes. |
| Backup durability → canonical replacement | Replacement is forbidden until exact original bytes have a verified durable backup. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-03-10 | Elevation of Privilege | recovery path | mitigate | No request path/destination; active-session fixed root; exclusive backup creation. |
| T-03-11 | Denial of Service | recovery race | mitigate | Full fingerprint precondition inside the existing per-draft queue. |
| T-03-12 | Information Disclosure | validation response | mitigate | Safe relative path and bounded structured details only; raw bytes remain server-side. |
