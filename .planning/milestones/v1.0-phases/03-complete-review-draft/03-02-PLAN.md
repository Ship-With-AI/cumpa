<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → loopback mutation API | Operation, revision, IDs and text are untrusted; no repository/path/object authority may cross. |
| Concurrent tabs → canonical draft | Both tabs may hold the same stale aggregate revision. |
| Validated draft → repository filesystem | Success is truthful only after durable atomic replacement. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-03-04 | Tampering | concurrent mutation | mitigate | Queue, reload, aggregate revision compare, one reducer operation, full validation, atomic replace in one critical section. |
| T-03-05 | Elevation of Privilege | mutation DTO | mitigate | Strict discriminated schemas and inherited bearer/Host/Origin guards; no path/ref/OID/replacement authority. |
| T-03-06 | Repudiation | accepted state | mitigate | Canonical response only after persistence; revision/timestamp transition and raw-byte evidence. |
| T-03-07 | Information Disclosure | errors/conflicts | mitigate | Latest canonical view only for authenticated session; bounded generic errors omit secrets and absolute paths. |
| T-03-08 | Denial of Service | text/document size | mitigate | Reuse reconciled bounded text/document schemas and serialize one active write. |
| T-03-SC | Tampering | dependencies | mitigate | No new package; use reconciled Node/Zod/Fastify stack. |
</threat_model>
