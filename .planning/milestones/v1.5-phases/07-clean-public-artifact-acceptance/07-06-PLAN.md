## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| child process diagnostics → driver output | Child stdout and stderr can carry the hosted support origin and absolute paths. |
| per-path reports → durable evidence | Report contents feed the consolidated committed record. |
| driver-owned shared support HOME → all child runs | One support identity is deliberately shared; its location must never leak into evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-38 | Information Disclosure | child diagnostics | mitigate | Failures are reported through the existing origin-redacting child wrapper so the hosted support origin never appears in output. |
| T-07-39 | Information Disclosure | per-path reports | mitigate | Private-value scan over the serialized report before writing, logical tokens instead of expanded paths, and an atomic `wx` mode `0o600` write followed by a link. |
| T-07-40 | Repudiation | blocked rows absorbed into a pass | mitigate | A blocked support row forces the enclosing path status to blocked with a named reason; only an all-rows-passed path may be reported as passed. |
| T-07-41 | Spoofing | wrong install source credited | mitigate | Each parsed bridge record's install source is asserted equal to the source requested for that child invocation. |
| T-07-42 | Tampering | report overwrite | mitigate | A new absolute report path is required and an existing file is refused, matching the local-archive driver's guard. |
| T-07-43 | Tampering | Cumpa checkout | mitigate | A source-control snapshot is captured before the run and asserted unchanged afterwards. |
| T-07-44 | Denial of Service | leftover shared support HOME | mitigate | The shared support HOME is created by the driver, reused read-through by children, and removed in `finally` after the reports are written. |
| T-07-45 | Tampering | local-archive regression | mitigate | The `accept:runtime-artifact` script is asserted byte-identical, the acceptance configuration keeps its original two entries alongside the two additions, and the local-archive driver's Playwright invocation is narrowed to two explicit positional filters whose `--list` resolution is asserted to be exactly the two original spec files. |
| T-07-57 | Repudiation | ACC-04 coverage gap across windows | mitigate | Each window's report records which window it ran and asserts the support bridge carries exactly that window's rows; the consolidated writer requires all three states per path over both windows and turns any missing state into a blocked row with a named reason and `substituted` false. |
| T-07-SC | Tampering | package-manager installs | mitigate | No dependency is added; installs happen only through the plan 07-02 adapters against the identity-pinned artifact. |
</threat_model>
