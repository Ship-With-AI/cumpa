## Trust Boundaries
| Boundary | Description |
|---|---|
| Stable checkout -> private packing tree | Trusted source bytes are copied and only the packed manifest version may change; source package/lock never change. |
| Producer evidence -> verifier profile | Evidence is untrusted input; a trusted explicit profile fixes expected purpose/version/projection before hashes/content are accepted. |
| Archive custody -> installed npm prefix | Exact rehashed bytes cross into isolated consumer state with scripts disabled and no inherited npm credentials. |
| Configured support input -> durable evidence | The canonical origin is build-only input; durable records retain only its approved fingerprint/configured state. |
| Historical Phase 4 custody -> bootstrap cycle | Old accepted bytes are immutable history and are not a producer input, fallback or bootstrap source. |
