<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Stripe → webhook | Untrusted network bytes claim payment; only official signature verification authenticates them. |
| Hosted process → Stripe API | Retrieved current Session/line items establish invariant facts. |
| Hosted process → PostgreSQL | A grant becomes authoritative only after one durable transaction. |
| Public status caller → hosted service | Unguessable installation correlation ID crosses an unauthenticated, rate-limited HTTPS lookup. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-02-SP | Spoofing | HIGH | Stripe webhook | mitigate | Official SDK verifies untouched bytes and endpoint secret before any retrieval or mutation. |
| T-01-02-TM | Tampering | HIGH | Payment details | mitigate | Retrieve live Session/line items and require link, price, quantity, currency, 4999 total, mode, paid state, environment, installation, and email invariants. |
| T-01-02-RP | Repudiation | HIGH | Duplicate/unordered events | mitigate | Unique event/session constraints plus one transaction and durable timestamps make fulfillment replay-safe. |
| T-01-02-ID | Information Disclosure | HIGH | Secrets/identity/logs | mitigate | Environment-only credentials, keyed normalized email, bounded redacted logs, public status vocabulary only. |
| T-01-02-EL | Elevation of Privilege | HIGH | Entitlement grant | mitigate | No browser/redirect/local claim route reaches fulfillment; SQL mutation is private to verified webhook/recovery paths. |
| T-01-02-DS | Denial of Service | MEDIUM | Public endpoints | mitigate | Strict sizes/identifiers, Fastify body limits, provider/DB timeouts, deployment rate limits in Plan 01-05. |

Execution MUST stop if any HIGH test or review finding is unresolved. No HIGH threat is accepted or transferred.
</threat_model>
