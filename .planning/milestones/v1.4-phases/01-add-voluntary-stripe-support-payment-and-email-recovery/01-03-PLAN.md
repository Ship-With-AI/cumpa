<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Anonymous caller → recovery request | Untrusted email/IP must not learn entitlement existence or trigger unlimited mail. |
| Inbox/browser → magic confirmation | Possession of a short-lived link proves email control only after explicit POST. |
| Poll bearer → challenge status | Narrow token may read only one challenge's coarse lifecycle. |
| Hosted service → Resend | Plaintext email exists only in transient HTTPS delivery request. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---:|---|---|---|
| T-01-03-EN | Information Disclosure | HIGH | Recovery request/status | mitigate | Identical 202/status vocabulary, decoy challenges, keyed lookup, aligned throttling, response comparison tests. |
| T-01-03-RP | Spoofing/Tampering | HIGH | Magic token | mitigate | Independent 256-bit token, HMAC digest, 15-minute expiry, installation binding, row lock, one POST consumption. |
| T-01-03-SC | Denial of Service | HIGH | Link scanners | mitigate | GET is inert; only explicit same-origin POST consumes. |
| T-01-03-XI | Elevation of Privilege | HIGH | Cross-installation restore | mitigate | Challenge stores installation ID; transaction inserts only that binding and rejects replay/concurrency. |
| T-01-03-PI | Information Disclosure | HIGH | Email/log/provider | mitigate | No durable plaintext email, no identity in URLs/status/logs, TLS Resend call, secret redaction. |
| T-01-03-FL | Denial of Service | MEDIUM | Email flooding | mitigate | Per-IP 5/hour and keyed-email 3/15-minute persisted windows; limited requests retain generic response. |

Execution MUST stop on any unresolved HIGH finding. No HIGH risk is accepted or transferred.
