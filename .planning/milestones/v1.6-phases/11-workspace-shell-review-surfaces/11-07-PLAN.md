<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository → inline comment cards | Comment bodies, display paths, and recorded anchor bytes are repository- and draft-derived and render directly inside the diff panes. |
| card geometry → line attribution | The inline card's measured height drives the paired empty zone. A desynchronised pair silently misattributes a comment to the wrong code line. |
| stylesheet → live surfaces | The deleted components share rules with `App.vue`'s empty states, `ReviewPanel.vue`'s cards, and the Phase 6 prototype. Deleting a shared rule breaks a surface no test for the deleted file covers. |

Task 1 verifies against `tests/integration/monaco-anchor.spec.ts` and the `.review-main` overflow canary, and asserts equal paired-zone heights at two widths through the re-measure path plan 02 fixed, rather than hard-coding heights. |
