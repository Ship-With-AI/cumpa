<interfaces>
- `package.json` declares a private `0.0.0` package, Node `>=24`, a generated `diff-review` bin at `dist/bin/diff-review.mjs`, and `npm run build`; `scripts/build-bin.mjs` makes that wrapper executable and points it only at compiled runtime output.
- `src/domain/errors.ts` requires Git 2.43.0 or newer with the machine protocols used by Diff Review. `src/cli/picker.ts` prompts for base first and head second. `src/cli/confirm.ts` displays the selected base/head/merge-base OIDs and states that the session does not follow moving refs. Dirty worktrees contribute committed HEAD only.
- `src/cli/run.ts` launches from `process.cwd()`, binds only to an ephemeral `127.0.0.1` port, prints the URL before attempting to open a browser, and tells the user to press Ctrl+C to stop.
- `src/server/draft-loader.ts` stores drafts beneath `.diff-review/drafts/`; the filename is the 64-hex domain-separated SHA-256 comparison key produced by `src/domain/comparison-key.ts` from ordered full base and head commit OIDs. It is not a literal `<baseOid>..<headOid>` filename.
- `src/server/export-store.ts` publishes `.diff-review/exports/<baseOid>..<headOid>/review.json` and `review.md` as one validated pair. `ExportSection.vue` states that export uses the accepted revision, excludes unsaved tab text, and does not apply, stage, commit, or push changes.
- `src/git/availability.ts` permits regular UTF-8 text up to `1_048_576` bytes per inspected blob side. Binary, non-UTF-8, oversized, symlink, submodule, unsupported mode/type, and missing-object cases remain listed but are not reviewable. The implementation does not classify arbitrary generated source files; `.diff-review/` output is explicitly excluded from the reviewed inventory.
- `KeyboardHelp.vue` is the exact shortcut reference: Alt+Shift+[ and Alt+Shift+] for files; Shift+F7 and F7 for changes; Option+Enter on macOS or Alt+Enter on Windows/Linux to add or focus a line comment; Command+Enter on macOS or Ctrl+Enter on Windows/Linux to add the comment; Escape to discard or close the composer; Tab/Shift+Tab for controls; Arrow keys plus Enter in the changed-file tree; Alt+F1 for Monaco accessibility help.
