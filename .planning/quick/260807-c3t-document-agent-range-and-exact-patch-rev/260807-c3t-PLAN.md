<interfaces>
- `AgentReviewRequestSchema` is a readonly discriminated union on `mode`. Both alternatives are strict objects with `kind: "compare.review-request"` and `schemaVersion: 1`; unknown fields and mixed modes are rejected.
- Revision mode is `{ mode: "revisions", revisions: { base, head, pathspecs? } }`. `pathspecs` defaults to an empty array, preserves order, and is passed to native Git. Base must resolve as an ancestor of head for this explicit range mode; accepted revisions are pinned to full object IDs for the session.
- Exact-patch mode is `{ mode: "patch", patch: { content, target: { kind: "repository" | "worktree" } } }`. Repository grounding checks the current `HEAD` tree; worktree grounding checks current on-disk entries. Patch preimages and modes must match the chosen target exactly before Compare freezes review bytes; Compare does not apply the patch.
- The complete stdin document is limited to 1,048,576 bytes and must be one non-empty, valid UTF-8 JSON document. Every revision/pathspec Git argument is non-empty valid Unicode without NUL and at most 4,096 UTF-8 bytes; at most 256 pathspecs are accepted. Patch content is non-empty valid Unicode without NUL and is additionally constrained by the total request ceiling, so JSON overhead means usable patch content is smaller than 1 MiB.
- `runOrdinaryAction` leaves TTY stdin with the existing interactive CLI and owns non-TTY stdin as the agent protocol. Attached sessions print the loopback URL and fallback guidance through stderr, open the browser, keep stdout empty while waiting, and reserve stdout for canonical review bytes delivered by successful Finish.
- Successful Finish delivers canonical bytes once, waits for the Finish response to settle, closes the loopback server, and exits zero. Revision conflicts and other non-completed Finish results do not emit canonical stdout. Bounded request/range/grounding/delivery failures leave stdout empty and exit non-zero; Ctrl+C cancellation before delivery exits 130 without partial canonical output.
- Every attached launch creates a random `agent-` plus 32-lowercase-hex storage scope. Saved draft state uses that isolated repository-local scope rather than an ordinary comparison key or a previous agent session. Exact-patch review content comes from a private frozen snapshot for the session and never falls back to later live bytes; the temporary snapshot is disposed when the server closes.
</interfaces>
