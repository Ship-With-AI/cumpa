<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| poller → reviewer awareness | Selector drift and patch drift are detected asynchronously. If the shell hides a warning behind a closed dialog, the reviewer approves a comparison whose sources have moved. |
| draft file → workspace availability | Corrupt, schema-invalid, and newer drafts must block mutation, not degrade silently. |
| assistive technology → announcement queue | Duplicate live owners produce repeated or conflicting speech, which in practice means the reviewer stops trusting it. |
