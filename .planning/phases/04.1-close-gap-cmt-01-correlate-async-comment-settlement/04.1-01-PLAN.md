<interfaces>
Use one controller-local, monotonically increasing numeric `requestId` as the opaque browser-session identity. Add it to the pending composer and emitted `persist-comment` command. Every `add-succeeded`, `add-duplicate`, and `add-failed` event carries `fileId` plus `requestId`; success/duplicate additionally carry the server-derived `WorkspaceComment`, while failures retain the existing bounded message. The reducer addresses `state.files[event.fileId]` and mutates only when that file has a `pending` composer with the same `requestId`. A mismatch, absent origin file, or already-replaced composer returns the original state with no commands.
</interfaces>
