<objective>
Re-derive and wire the stray-literal and token-structure gate that already exists at `scripts/verify-semantic-css.mjs`, so that after this phase a future colour drift fails a command a developer can actually run.

Output: an audit whose value authority is the canonical root, whose retired-vocabulary list covers this phase's renames, whose Vue coverage includes both prototypes, and which is reachable as `npm run verify:semantic-css`.
</objective>

<decisions>
- **D-NO-VALUE-TABLE — the audit asserts shape, never values.** The `expectedValues` table is deleted, not re-derived. Re-deriving it would keep a name-to-value table alongside the canonical root, and a reviewer could legitimately call that a second palette even with a check holding them equal. `08-UI-SPEC.md` stays the human value authority and `src/web/styles.css :root` the machine one. What the audit gains instead is a shape rule with real teeth: every canonical token's value must be a lowercase canonical colour notation, a `var()` alias naming another canonical token, or a non-colour value.
- **D-NO-SECOND-PARSER — the audit does not normalise colour bytes.** `scripts/verify-semantic-css.mjs` is plain Node and cannot import the TypeScript `src/web/theme/token-contract.ts`. Rather than reimplement the normaliser there — which would recreate the two-parsers-that-drift bug this phase exists to kill — the audit checks notation shape only. Byte equality between CSS and Monaco is owned by `tests/unit/monaco-theme.test.ts`, which does import the shared transform.
- **D-ONE-GATE — do not author a second stray-literal checker.** `assertDirectColorConfinement` at `scripts/verify-semantic-css.mjs:294-309` already implements the UI-SPEC's confinement rule verbatim, including the `transparent` and `currentColor` exemptions and the forced-colors system-keyword allowance. Extend it; do not write a parallel check in Vitest.
- **D-BUILD-FIRST — the audit's npm verb builds before it audits.** The script reads `dist/web/index.html` at `scripts/verify-semantic-css.mjs:8` and the stylesheets it links at `:447-466`, but nothing in it triggers a build and `dist/` is gitignored. Running it against stale or absent output audits the wrong bytes or crashes. The verb therefore runs `build:web` first.
</decisions>
