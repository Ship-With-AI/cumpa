<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public GitHub marketplace → isolated OMP profile | Marketplace catalog and plugin files cross into the profile and become executable agent instructions. |
| agent-supervised child process → harness | The CLI the agent launches and its canonical output cross back into the evidence record. |
| isolated profile → operator's real OMP profile and credentials | The real profile, its plugins, and its authentication must remain untouched. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-28 | Spoofing | skill provenance | mitigate | The discovered SKILL.md SHA-256 must equal the published Phase 6 digest and its realpath must be outside the Cumpa checkout; a hand copy from the repository is forbidden by an explicit acceptance criterion. |
| T-07-29 | Spoofing | supervised CLI identity | mitigate | The resolved executable realpath must be contained in the isolated npm prefix produced by the pinned global adapter, and the bundled checker must have reported the exact pinned version first. |
| T-07-30 | Repudiation | readiness reported as completion | mitigate | Readiness and terminal exit are two separately timestamped observations with a strict ordering assertion, and the result is accepted only after a zero exit. |
| T-07-31 | Spoofing | fabricated canonical result | mitigate | The result is parsed with the product's canonical schema and its summary and comment digests are compared against what the browser walkthrough actually entered. |
| T-07-32 | Tampering | operator's real OMP profile | mitigate | Read-only digest capture of the real installed-plugins and marketplaces state before the run and an unchanged assertion in `finally`; every profile path used is inside the owned temporary root. |
| T-07-33 | Elevation of Privilege | provider credential leakage into the profile | mitigate | The five provider credential variables the frozen prefix unsets are removed from the profile environment; the operator authenticates the isolated profile only. |
| T-07-34 | Tampering | skill self-installing or upgrading the CLI | mitigate | The executed command trace is asserted free of install, upgrade, npx, source-checkout, and local-tarball commands using the existing forbidden-product-command assertion. |
| T-07-35 | Information Disclosure | marketplace evidence row | mitigate | Logical tokens replace expanded paths, the serialized record is scanned for every private value before the atomic `wx` mode `0o600` write, and no credential or raw provider payload is recorded. |
| T-07-36 | Tampering | reviewed fixture and Cumpa checkout | mitigate | Source-control snapshots are captured before and asserted unchanged after; the agent is instructed to review, and Cumpa never applies, stages, commits, or pushes. |
| T-07-37 | Denial of Service | hung agent or CLI process | mitigate | The driver bounds the readiness wait and the terminal wait with explicit deadlines that resolve into a blocked row, and cleans up the profile, install, and fixture in `finally`. |
| T-07-SC | Tampering | package-manager installs | mitigate | The only fetched npm package is the identity-pinned artifact under acceptance, installed through the plan 07-02 adapter; the marketplace collection is fetched from the public repository and bound by the published Phase 6 commit object id and file digest. |
</threat_model>
