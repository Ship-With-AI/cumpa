<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Workspace focus-comment command → transient UI selection | An existing trusted command ID may affect presentation and DOM focus, but must not gain persistence or mutation authority. |
| Draft comments/paths → grouped rail DOM | Untrusted text and identity records must remain text and fixed data attributes, not HTML, selectors beyond escaped existing IDs, or actions. |
| Lifecycle pending state → per-row feedback | Operation-wide state can spoof progress on unrelated rows unless correlated with pendingFocus.commentId. |
| Visual hierarchy → reviewer interpretation | Selection, focus, lifecycle, anchor degradation, and destructive intent must remain distinct when combined. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|-----------|----------|----------|-----------|-------------|-----------------|
| T-07-11 | Tampering | high | selected comment identity | mitigate | Source selection only from existing `focus-comment`, clear against current IDs, keep it non-persistent/non-exported, use existing CSS.escape for DOM lookup, and prove transfer/clear in production browser flow. |
| T-07-12 | Spoofing | high | selected/focus/lifecycle/anchor cues | mitigate | Use independent rail, outer focus ring, visible Selected, lifecycle and anchor badges, destructive outline, and overlap assertions; never use focus or one fill for multiple meanings. |
| T-07-13 | Spoofing | high | localized busy feedback | mitigate | Require operation kind plus `pendingFocus.commentId`, exact progressive verbs, spinner and aria-busy only on the acted-on row, and browser assertion that siblings do not claim progress. |
| T-07-14 | Tampering | high | comment/path rendering and actions | mitigate | Render Vue text only, retain exact verification gates and action emits, forbid guessed anchors/generic row click targets/new mechanics, and exercise stale/unavailable controls. |
| T-07-15 | Denial of Service | medium | grouped long records | mitigate | Use min-width zero, anywhere wrapping, divider rows, and existing scroll owner; cover multiple groups/long content without page overflow or hidden controls. |
| T-07-SC | Tampering | low | npm supply chain | accept | No install, upgrade, or manifest/lockfile modification occurs. |

High-severity gate: T-07-11 through T-07-14 must be mitigated by exact command binding, visible-channel separation, pending correlation, and focused browser evidence; none may be accepted or transferred.
</threat_model>
