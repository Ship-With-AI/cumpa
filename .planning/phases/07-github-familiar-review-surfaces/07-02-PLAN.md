## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Repository/draft comment and path text → Vue/VNode card content | Untrusted review text must remain text and must not become HTML, a selector, icon path, class, or executable content. |
| Workspace lifecycle/anchor records → visual badges | Two independent state axes must not be merged or visually spoofed. |

| Pending persistence → user-visible acceptance | Busy presentation must not imply that a comment is accepted before the existing canonical response. |
